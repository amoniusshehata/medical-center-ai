# Medical Center AI Assistant — MVP

Prototype for a medical-center AI receptionist dashboard.

## Current MVP
- Center profile management
- Clinics management
- Doctors and schedules
- Services and prices
- FAQ / knowledge base
- Test AI chat using saved center data
- Local persistence with localStorage
- Arabic RTL responsive UI

## Important
This is a demo/prototype. It does not connect to WhatsApp, Messenger, a real booking system, or patient records yet. Do not enter real patient data.

## Next phase
1. Backend + database
2. Authentication and multi-center accounts
3. RAG knowledge base for PDFs/documents
4. Real appointment/booking integration
5. WhatsApp Business API
6. Facebook Messenger
